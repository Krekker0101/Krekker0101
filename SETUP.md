# Profile kit

- `README.md` is the GitHub profile page.
- `ARCHITECTURE.md` contains GitHub-native Mermaid diagrams for selected public repositories.
- `assets/profile-banner.gif` is a locally stored animated banner (no external widget or tracking).
- `assets/profile-banner.svg` is the static fallback/source artwork.

GitHub renders Mermaid fenced code blocks and standard Markdown tables natively. The `<details>` sections are native collapsible HTML supported by GitHub's README renderer. No GitHub Actions workflow, third-party badge service, analytics widget, or client-side JavaScript is required.
